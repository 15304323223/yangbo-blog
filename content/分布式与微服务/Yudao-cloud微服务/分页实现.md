# 分页实现（前后端完整链路）

> **一句话概括**：前端 `pageNo` + `pageSize` 两个参数传进来，后端用 MyBatis Plus 分页插件查出数据和总数，包装成 `PageResult` 返回。芋道把它标准化成了 **`PageParam` 入参 + `PageResult` 出参** 的统一约定。

---

## 零、先建立整体印象：翻一本 1000 页的书

> 🧒 **费曼第 1 段 · 5 岁小孩也能懂**

一本 1000 页的书，你不会一次全看。你会：

- 一次看 **10 页**（= `pageSize` 每页条数）
- 现在看**第 5 页**（= `pageNo` 页码），也就是第 41~50 页

数据库也一样。表里 100 万条数据，不可能一次全查出来（内存爆炸 + 慢），所以要"**一页一页翻**"。

**前端需要知道两件事**：这一页的**数据列表** + **总共多少条**（才能显示"共 100 页"）。

---

## 一、原理篇：一次分页请求的完整旅程

```
┌─────────────────────────────────────────────────┐
│ ① 前端：点击第 2 页                                │
│    { pageNo: 2, pageSize: 10, name: "芋道" }      │
└────────────────────┬────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────┐
│ ② 后端 Controller：@Valid TenantPageReqVO pageVO │
│    自动校验 pageNo ≥ 1、pageSize ≤ 100            │
└────────────────────┬────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────┐
│ ③ Mapper：LambdaQueryWrapperX 拼条件              │
│    likeIfPresent(名字) / eqIfPresent(状态)         │
└────────────────────┬────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────┐
│ ④ MyBatis Plus 分页插件：自动改写 SQL               │
│    SELECT ... LIMIT 10, 10                        │
│    SELECT COUNT(*) ...     ← 额外查总数            │
└────────────────────┬────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────┐
│ ⑤ 返回 PageResult<XxxRespVO>                      │
│    { list: [...], total: 87 }                     │
└─────────────────────────────────────────────────┘
```

## 二、应用篇

### 2.1 前端：Vue 页面

```vue
<template>
  <!-- ① 搜索栏 -->
  <el-form :model="queryParams" :inline="true">
    <el-form-item label="租户名">
      <el-input v-model="queryParams.name" clearable
                @keyup.enter.native="handleQuery" />
    </el-form-item>
    <el-form-item>
      <el-button type="primary" @click="handleQuery">搜索</el-button>
      <el-button @click="resetQuery">重置</el-button>
    </el-form-item>
  </el-form>

  <!-- ② 数据表格 -->
  <el-table v-loading="loading" :data="list"> ... </el-table>

  <!-- ③ 分页组件（关键） -->
  <pagination
    v-show="total > 0"
    :total="total"
    :page.sync="queryParams.pageNo"
    :limit.sync="queryParams.pageSize"
    @pagination="getList" />
</template>

<script>
import { getTenantPage } from "@/api/system/tenant";

export default {
  data() {
    return {
      loading: true,
      total: 0,          // 总条数
      list: [],          // 当前页数据
      queryParams: {
        pageNo: 1,       // 页码，从 1 开始
        pageSize: 10,    // 每页条数
        name: null,      // 搜索条件：租户名
        status: undefined,
      },
    };
  },
  created() {
    this.getList();      // 进入页面就查一次
  },
  methods: {
    getList() {
      this.loading = true;
      getTenantPage(this.queryParams).then(response => {
        this.list = response.data.list;    // 数据列表
        this.total = response.data.total;  // 总条数
        this.loading = false;
      });
    },
    handleQuery() {
      this.queryParams.pageNo = 1;   // ⚠️ 搜索时要重置到第 1 页
      this.getList();
    },
  },
};
</script>
```

> ⚠️ **最容易漏的细节**：搜索时必须 `pageNo = 1`。
> 否则你在第 5 页搜索"张三"，结果只有 2 条时，会显示空列表（因为还在第 5 页）。

### 2.2 后端：Controller

```java
@Tag(name = "管理后台 - 租户")
@RestController
@RequestMapping("/system/tenant")
public class TenantController {

    @Resource
    private TenantService tenantService;

    @GetMapping("/page")
    @Operation(summary = "获得租户分页")
    @PreAuthorize("@ss.hasPermission('system:tenant:query')")   // 功能权限
    public CommonResult<PageResult<TenantRespVO>> getTenantPage(@Valid TenantPageReqVO pageVO) {
        PageResult<TenantDO> pageResult = tenantService.getTenantPage(pageVO);
        // DO 转 VO 后再返回（不直接返回数据库实体）
        return success(TenantConvert.INSTANCE.convertPage(pageResult));
    }
}
```

### 2.3 入参：`PageParam`（统一分页参数）⭐

```java
@Schema(description = "分页参数")
@Data
public class PageParam implements Serializable {

    private static final Integer PAGE_NO = 1;
    private static final Integer PAGE_SIZE = 10;

    @Schema(description = "页码，从 1 开始", required = true, example = "1")
    @NotNull(message = "页码不能为空")
    @Min(value = 1, message = "页码最小值为 1")
    private Integer pageNo = PAGE_NO;

    @Schema(description = "每页条数，最大值为 100", required = true, example = "10")
    @NotNull(message = "每页条数不能为空")
    @Min(value = 1, message = "每页条数最小值为 1")
    @Max(value = 100, message = "每页条数最大值为 100")     // ⚠️ 防止一次查太多
    private Integer pageSize = PAGE_SIZE;
}
```

**业务分页 VO 继承它，再加自己的搜索条件**：

```java
@Data
@EqualsAndHashCode(callSuper = true)
public class TenantPageReqVO extends PageParam {

    @Schema(description = "租户名", example = "芋道")
    private String name;

    @Schema(description = "联系人", example = "芋艿")
    private String contactName;

    @Schema(description = "租户状态（0正常 1停用）")
    private Integer status;

    @DateTimeFormat(pattern = FORMAT_YEAR_MONTH_DAY_HOUR_MINUTE_SECOND)
    @Schema(description = "创建时间")
    private LocalDateTime[] createTime;    // 时间范围，前端传数组
}
```

> 💡 **为什么 `pageSize` 要限制最大 100？** 防止前端传 `pageSize=999999` 把数据库打垮。这是**接口安全的基本素养**。

### 2.4 出参：`PageResult`（统一分页结果）

```java
@Schema(description = "分页结果")
@Data
public final class PageResult<T> implements Serializable {

    @Schema(description = "数据", required = true)
    private List<T> list;

    @Schema(description = "总量", required = true)
    private Long total;
}
```

### 2.5 Mapper：条件构造（关键）⭐

```java
@Mapper
public interface TenantMapper extends BaseMapperX<TenantDO> {

    default PageResult<TenantDO> selectPage(TenantPageReqVO reqVO) {
        return selectPage(reqVO, new LambdaQueryWrapperX<TenantDO>()
            .likeIfPresent(TenantDO::getName, reqVO.getName())              // 名字不为空才 like
            .likeIfPresent(TenantDO::getContactName, reqVO.getContactName())
            .likeIfPresent(TenantDO::getContactMobile, reqVO.getContactMobile())
            .eqIfPresent(TenantDO::getStatus, reqVO.getStatus())            // 状态不为空才 =
            .betweenIfPresent(TenantDO::getCreateTime,
                              reqVO.getBeginCreateTime(),
                              reqVO.getEndCreateTime())                     // 时间范围
            .orderByDesc(TenantDO::getId));                                 // 按 id 倒序
    }
}
```

> 💡 **`xxxIfPresent` 是芋道的增强**（`LambdaQueryWrapperX`）：
> - 原生 MyBatis Plus：`if (name != null) wrapper.like(...)`
> - 芋道：`.likeIfPresent(...)` 一行搞定，**值不为空才拼条件**
>
> 这一个小小的封装，能让分页查询代码少写一半的 if。

## 三、进阶篇

### 3.1 深分页问题（面试高频）⭐

**问题**：`LIMIT 1000000, 10` 为什么慢？

因为 MySQL 要**先扫描 1000010 行，再扔掉前 100 万行**，只返回后 10 行。

| 方案 | 做法 | 适用 |
|---|---|---|
| **子查询优化** | 先查 id 再关联：`SELECT * FROM t WHERE id IN (SELECT id FROM t LIMIT 1000000,10)` | 通用 |
| **游标（推荐）** | 记录上一页最大 id：`WHERE id > 上一页最大id LIMIT 10` | ✅ **大数据量翻页首选** |
| **限制翻页深度** | 只允许翻到前 100 页 | 搜索引擎类产品（百度、Google 都这么做） |
| **延迟关联** | 先分页查 id，再 join 回主表取数据 | 大表 |

> 💡 详见 [[07_MySQL 与 SQL 优化]]。

### 3.2 COUNT(*) 的性能问题

MyBatis Plus 分页会自动执行两条 SQL：

```sql
SELECT * FROM tenant WHERE ... LIMIT 0, 10;      -- 查数据
SELECT COUNT(*) FROM tenant WHERE ...;           -- 查总数
```

**问题**：大表上 `COUNT(*)` 很慢，甚至比查数据还慢。

| 优化方案 | 做法 |
|---|---|
| **关闭总数查询** | MyBatis Plus 支持 `Page.setSearchCount(false)` |
| **用估算值** | 用 `EXPLAIN` 的 rows 估算，或单独的计数表 |
| **缓存总数** | 总数变化不频繁时，缓存起来 |
| **异步查总数** | 先返回数据，总数异步算 |

> 💡 **MyBatis Plus 的小优化**：如果总数 = 0，就**不再查列表**（省一条 SQL）。官方原文："在分页数量为 0 时，就不多余查询分页的列表"。

### 3.3 分页常见坑

| 坑 | 现象 | 解决 |
|---|---|---|
| **搜索不重置页码** | 在第 5 页搜索后列表是空的 | `handleQuery()` 里 `pageNo = 1` |
| **没限制 pageSize** | 被恶意传 999999，拖垮数据库 | `@Max(100)`（芋道已加） |
| **排序字段不唯一** | 分页数据错乱/重复 | 排序加 `id` 兜底：`ORDER BY create_time DESC, id DESC` |
| **数据实时变化** | 翻页时数据新增/删除，导致漏数据 | 用游标分页；或接受最终一致 |
| **深分页慢** | 翻到第 10000 页卡死 | 见 3.1 |
| **没建索引** | 分页 + 排序 + 条件全表扫描 | 建**联合索引**（条件字段 + 排序字段） |

### 3.4 芋道分页设计的三个优点

1. **`PageParam` + `PageResult` 统一约定**：所有分页接口长得一样，前端组件可以完全复用
2. **`xxxIfPresent` 条件构造**：少写一半 if
3. **`pageSize` 最大值限制**：接口安全的基本防护

> 💡 这套约定值得直接抄到自己的项目里。

## 四、一句话总结

| 问题 | 答案 |
|---|---|
| 前端传什么 | `pageNo`（从第 1 页）+ `pageSize`（每页条数）+ 搜索条件 |
| 后端入参 | 继承 `PageParam` 的 `XxxPageReqVO` |
| 后端出参 | `PageResult<T>` = `{ list, total }` |
| 条件怎么拼 | `LambdaQueryWrapperX` 的 `xxxIfPresent` 系列 |
| 必做 | ① 搜索重置页码 ② 限制 pageSize 上限 ③ 排序加 id 兜底 |
| 深分页 | 用**游标分页**（`WHERE id > 上一页最大id`） |
